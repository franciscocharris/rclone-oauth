About this site

This site exists to host the required Application home page and Privacy Policy for a private Google Cloud OAuth client that I registered for my own use. Google requires both to be publicly reachable when an OAuth consent screen is configured.

The application is rclone — an open-source command-line program for syncing files with Google Drive. I use it to run encrypted, restic-based backups of my own development environment to my own personal Google Drive account.

What this app is not

  • It is not a service offered to other people.
  • It is not published to the Play Store or any app directory.
  • It has fewer than 100 users — namely, one.
  • It does not send any data anywhere. The process runs locally on my own machine.

Data access

The OAuth grant is read/write on Google Drive, used solely to create and maintain the folders that hold my personal backups. No data leaves my Drive account, and nothing is shared with third parties.

Full details are in the privacy policy.
